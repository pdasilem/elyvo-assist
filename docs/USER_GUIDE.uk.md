# Elyvo Assist — Посібник користувача

> 🌐 Цей посібник також доступний такими мовами: [English](USER_GUIDE.md) · [Беларуская](USER_GUIDE.be.md) · [Deutsch](USER_GUIDE.de.md) · [Español](USER_GUIDE.es.md) · [Français](USER_GUIDE.fr.md) · [Italiano](USER_GUIDE.it.md) · [Português](USER_GUIDE.pt.md) · [Русский](USER_GUIDE.ru.md) · **Українська**

Elyvo Assist — це десктопний ІІ-асистент для зустрічей, досліджень і мозкових штурмів. Він працює як напівпрозорий оверлей поверх будь-якого вікна і викликається гарячою клавішею. Він може слухати ваш мікрофон і системний звук, розшифровувати мовлення в реальному часі, бачити ваш екран і відповідати на запитання з урахуванням контексту.

## Встановлення

Інсталятори та бінарні файли публікуються в [GitHub Releases](https://github.com/pdasilem/elyvo-assist/releases). Завантажте файл, що відповідає вашій платформі, з останнього релізу. Усі збірки 64-бітні (`x86_64` / Apple Silicon).

Кожен реліз містить для версії `X.Y.Z`:

| Платформа | Файл |
|-----------|------|
| Windows | `elyvo-assist-X.Y.Z-windows-x64-setup.exe` |
| macOS (Intel) | `elyvo-assist-X.Y.Z-macos-x64.dmg` |
| macOS (Apple Silicon) | `elyvo-assist-X.Y.Z-macos-arm64.dmg` |
| Debian / Ubuntu | `elyvo-assist-X.Y.Z-linux-x86_64.deb` |
| Arch / Manjaro | `elyvo-assist-X.Y.Z-1-x86_64.pkg.tar.zst` (+ `install.sh`) |

### Windows

1. Завантажте інсталятор `...-setup.exe` (NSIS).
2. Запустіть його і дотримуйтесь підказок. Застосунок встановлюється в `Program Files\Elyvo Assist`.
3. Запустіть **Elyvo Assist** з меню «Пуск».

### macOS

1. Завантажте `.dmg` для вашого процесора — `macos-x64` для Intel, `macos-arm64` для Apple Silicon (M1/M2/M3 і новіших).
2. Відкрийте образ диска і перетягніть **Elyvo Assist** у папку **Applications**.
3. Під час першого запуску macOS може попередити, що застосунок від нерозпізнаного розробника. Клацніть правою кнопкою миші на застосунку → **Open** → **Open**, щоб дозволити запуск.

> **Вимоги для Linux.** Elyvo Assist орієнтований на робочий стіл **KDE Plasma** на **Wayland**. Застосунок інтегровано з KWin (композитором KDE). Інші стільниці (GNOME тощо) можуть запускати застосунок, але поведінка вікна може відрізнятися. Також для захоплення мікрофона і системного звуку потрібен запущений сеанс **PipeWire**.

### Linux — Debian / Ubuntu

```bash
sudo apt install ./elyvo-assist-X.Y.Z-linux-x86_64.deb
```

`apt` самостійно підтягує залежності виконання (WebKitGTK 4.1, OpenSSL 3, PipeWire). У старіших версіях `apt` використовуйте `sudo dpkg -i ...`, а потім `sudo apt -f install`, щоб довстановити відсутні залежності.

### Linux — Arch / Manjaro

Найшвидший шлях — опублікований скрипт встановлення, який завантажує пакет, встановлює необхідні системні бібліотеки і запускає `pacman` за вас:

```bash
curl -fsSL https://github.com/pdasilem/elyvo-assist/releases/latest/download/install.sh -o install.sh
bash install.sh
```

Скрипт підтримує лише системи на базі `pacman` і встановить усі відсутні пакети виконання (GTK3, WebKit2GTK 4.1, PipeWire, libayatana-appindicator тощо).

Волієте зробити це вручну? Завантажте `.pkg.tar.zst` і встановіть його напряму:

```bash
sudo pacman -U elyvo-assist-X.Y.Z-1-x86_64.pkg.tar.zst
```

## Перший запуск

1. **Вхід.** Увійти можна за допомогою **електронної пошти й пароля**, **одноразового коду з листа** або через **Google**. Новий обліковий запис створюється на тому самому екрані (пошта → код підтвердження → встановлення пароля).
2. **Онбординг.** Короткий майстер налаштування проведе вас через кілька кроків — зокрема **дозволи** і **створення першого проєкту** — і завершиться кроком **«Про вас»**, де можна за бажанням додати файл (`.pdf`, `.doc`, `.docx`, `.md`, `.txt`), щоб дати асистенту більше контексту про вас. Це можна пізніше змінити у своєму **Профілі**.
3. **Початок роботи.** Після онбордингу відкривається **Дашборд**. Викликати оверлей чату можна будь-коли гарячою клавішею перемикання (за замовчуванням `Ctrl+\`).

## Дозволи

Щоб слухати і бачити ваш екран, Elyvo Assist потребує двох дозволів на рівні ОС, які запитуються під час онбордингу:

- **Мікрофон** — щоб фіксувати те, що ви говорите.
- **Захоплення екрана** — щоб функція *«Запитати про мій екран»* бачила активне вікно.

На **Windows** і **macOS** це вирішується через звичайні системні запити. У **Linux** надавайте дозволи, коли їх запитають; якщо ви випадково відхилили якийсь із них, надайте його в налаштуваннях приватності вашої ОС.

Самі налаштування звуку й мікрофона недоступні всередині застосунку — Elyvo завжди використовує **пристрій за замовчуванням**, заданий у системі.

> У Linux захоплення мікрофона і системного звуку використовує PipeWire та desktop portal. Переконайтеся, що PipeWire запущено (за замовчуванням він увімкнений в актуальних Manjaro та Ubuntu).

## Оверлей і гарячі клавіші

Elyvo Assist керується майже повністю з клавіатури, щоб ви могли користуватися ним, не відриваючись від зустрічі. Оверлей чату розташовується поверх інших вікон, його можна перетягувати.

Гарячі клавіші за замовчуванням (усі можна перепризначити в **Налаштування → Гарячі клавіші**):

| Дія | За замовчуванням | Що робить |
|-----|-------------------|-----------|
| Перемкнути видимість | `Ctrl+\` | Показати / приховати оверлей Elyvo |
| Запитати Elyvo | `Ctrl+Enter` | Запитати про екран або поточний звук |
| Очистити чат | `Ctrl+R` | Очистити поточну розмову |
| Почати / зупинити сесію | `Ctrl+Shift+\` | Почати або завершити сесію прослуховування |
| Перемістити оверлей | `Ctrl+↑ / ↓ / ← / →` | Перемістити вікно на екрані |
| Прокрутити відповідь | `Ctrl+Shift+↑ / ↓` | Прокрутити відповідь угору / униз |

Щоб перепризначити, відкрийте **Налаштування → Гарячі клавіші**, клацніть на сполученні клавіш і натисніть нову комбінацію.

## Огляд можливостей

### Сесії

**Сесія** — це період, коли Elyvo активно слухає і утримує контекст. Почати або зупинити сесію можна сполученням `Ctrl+Shift+\`. Під час сесії Elyvo захоплює ваш мікрофон і системний звук, розшифровує мовлення в реальному часі та зберігає поточну розшифровку як контекст для ваших запитань. Elyvo використовує **системний пристрій введення за замовчуванням** (змінити його в застосунку не можна); у налаштуваннях можна побачити виявлений пристрій і перевірити рівні мікрофона та системного звуку за допомогою індикаторів у реальному часі.

### Запит про ваш екран або звук

Натисніть **Запитати Elyvo** (`Ctrl+Enter`), і Elyvo відповість, спираючись на те, що зараз на екрані, та нещодавній звук/розшифровку як контекст — це зручно для «підсумуй, що щойно сказали», «що це за помилка» або «підготуй відповідь на це». Також будь-коли можна просто ввести звичайне повідомлення в поле чату.

### Швидкі дії

Під час сесії в чаті доступні п'ять дій в один клік. Вони **залежать від ролі**: кожна бере зміст із ситуації та мети активного режиму, тож та сама кнопка допомагає по-різному — ви відповідаєте, оцінюєте, ведете переговори чи навчаєтеся.

- **Assist** — суть, потрібна в моменті: відповідь на запитання, поставлене вам; еталонна відповідь або швидка оцінка, коли оцінюєте *ви*; повне розв'язання, якщо на скриншоті завдання. Це матеріал для роздумів, а не слова для промовляння вголос.
- **What should I say?** — одна наступна репліка, яку варто сказати вголос, вашим голосом, готова як є.
- **Follow-up questions** — набір із 3–4 запитань, які можна поставити далі, щоб просунути вашу мету: меню на вибір, а не одна фраза.
- **What did they mean?** — розшифровка останньої репліки співрозмовника: його думка, намір і невисловлене занепокоєння.
- **Recap** — до трьох пунктів про те, що змінилося, було вирішено чи запитано з моменту, коли ви звірялися востаннє.

Як працює зміна ролі: у режимі кандидата Assist відповідає на запитання, адресоване вам; у режимі оцінювача — дає еталонну відповідь, з якою можна звірити почуте; у переговорному режимі Follow-up questions перетворюються на запитання для з'ясування позиції. У режимі лекції чи вебінару, де ви здебільшого слухаєте, Assist пояснює щойно висловлену думку простіше, Follow-up questions стають запитаннями до спікера або перевіркою власного розуміння, а Recap допомагає надолужити пропущене після відволікання. Усім цим керує системний промпт активного режиму — кнопки залишаються тими самими (див. **Режими ІІ** нижче).

### Режими ІІ

**Режими** дозволяють налаштувати поведінку асистента для різних ситуацій. Кожен режим має власний системний промпт і необов'язковий шаблон нотаток. Керуйте ними в розділі **Режими**:

- Почніть із **Галереї шаблонів** — її шаблони надає сервер, і вони змінюються з часом — або створіть режим із нуля.
- Відредагуйте системний промпт, щоб задати тон, роль і правила для цієї ситуації.
- Додайте **файли режиму** — довідкові матеріали, які асистент має враховувати в цьому режимі.
- Позначте один режим як активний; загальний режим за замовчуванням доступний завжди.

### Фоновий ІІ-чат (Ambient)

Фоновий чат — це легкий, завжди доступний чат, який супроводжує вас у застосунку і може бути прив'язаний до проєкту. Він входить до платного тарифу (див. **Налаштування → Оплата**).

### Що дає ваш тариф

Elyvo працює на будь-якому тарифі; розширена підписка знімає обмеження і відкриває спільну роботу. Загалом вищий тариф дає:

- довші та частіші сесії;
- запас за кількістю проєктів і документів;
- можливість ділитися проєктом з іншими людьми — прийняти запрошення і працювати в чужому проєкті можна на будь-якому тарифі;
- використання застосунку більш ніж на одному пристрої одночасно;
- самонавчання асистента, щоб він ставав кращим від ваших сесій.

Що включає ваш поточний тариф і як його змінити — у **Налаштування → Оплата**. Де діє обмеження, застосунок повідомить про це в момент, коли ви його досягнете, а не відмовить мовчки.

### Проєкти

**Проєкти** групують пов'язані сесії і надають асистенту спільний, постійний контекст. У межах проєкту можна керувати:

- **Учасники** — переглянути, хто в проєкті, і запросити інших електронною поштою (кожен запрошений відображається як *в очікуванні*, доки не прийме запрошення). Надсилання запрошень потребує тарифу, що включає спільний доступ; прийняти запрошення і працювати в чужому проєкті можна на будь-якому тарифі.
- **Пам'ять** — факти й контекст, які асистент має пам'ятати між сесіями цього проєкту.
- **Правила** — вказівки, яких асистент дотримується в цьому проєкті.
- **Налаштування** — власні для проєкту **режим**, **мова відповідей** і **мова розшифровки**, а також **Збагачення контексту** — перемикач (за замовчуванням вимкнений), що дозволяє асистенту підтягувати релевантний контекст з ваших *інших* сесій у цьому ж проєкті (міжсесійна пам'ять).

Коли *вас* запрошують до чужого проєкту, запрошення з'являється вгорі розділу **Проєкти** з кнопками **Прийняти** / **Відхилити**. Фоновий чат можна прив'язати до проєкту, щоб відповіді спиралися на пам'ять і правила цього проєкту.

Якщо тариф власника перестає включати спільний доступ, спільний проєкт стає **доступним лише для читання** для всіх, доки з нього не приберуть учасників. Нічого не видаляється, і повний доступ повертається, щойно проєкт перестає бути спільним — або тариф знову включає спільний доступ.

### Документи

Elyvo може зберігати особисту бібліотеку довідкових документів, які можна відкрити як окремий оверлей просто під час роботи — зручно тримати під рукою нотатки, брифінг або чек-лист під час дзвінка.

- **Керування документами.** У **Налаштування → Ресурси** додавайте файли Markdown (`.md`) — до **1 МБ** кожен — у розділі *Ваші документи* або видаляйте непотрібні. Документи приватні й доступні лише вашому обліковому запису. Скільки документів можна зберігати, залежить від вашого тарифу.
- **Увімкнення для проєкту.** Для активного проєкту позначте документи, які хочете мати напохваті. Увімкнені документи **автоматично відкриваються вкладками** у переглядачі «Документи», коли ви відкриваєте його для цього проєкту. Увімкнення документа визначає, що показує переглядач для проєкту; вміст файлу при цьому не передається у відповіді асистента.
- **Відкриття переглядача.** У меню сесії оверлея чату (кнопка `···`) виберіть **Документи**. Він відкриється як окреме перетягуване вікно. Той самий пункт меню закриває його.
- **Читання та перемикання.** Кожен документ відкривається у власній вкладці. Кнопкою **+** відкрийте будь-який зі своїх документів, клацанням на вкладці перемикайтеся між ними, а **×** закриває вкладку. Вміст відображається як відформатований Markdown і відповідає темі чату та розміру шрифту.

### Календар і зустрічі

Підключіть **Google Календар** (у **Налаштування → Загальні**), щоб бачити майбутні зустрічі прямо в Elyvo. На картці зустрічі кнопка **«Приєднатися →»** просто відкриває посилання на дзвінок (Zoom/Meet/Teams) у браузері, а кнопка **«Почати нотатки»** запускає сесію прослуховування. Незадовго до зустрічі Elyvo також показує нагадування всередині застосунку з власною кнопкою **«Почати нотатки»**, яка робить обидві дії одразу — запускає сесію і відкриває посилання на дзвінок, — тож асистент слухає з моменту приєднання.

### Дашборд та історія

**Дашборд** — ваша домашня сторінка: він показує минулі сесії списком із групуванням за датами та пошуком (поле пошуку розташоване в шапці застосунку) і дозволяє відкрити деталі сесії на трьох вкладках — **Підсумок** (підсумок зустрічі), **Розшифровка** (захоплена розшифровка) і **Використання** (запитання, які ви ставили Elyvo під час сесії, та його відповіді). Використовуйте його, щоб переглядати зустрічі або повертатися до них. На вкладці **Зведення** кнопка копіювання копіює все зведення повністю.

### Пам'ять і самонавчання

Elyvo стає кращим із використанням. У своєму **Профілі** ви можете переглядати й редагувати:

- **Пам'ять користувача** — довгострокові факти про вас і ваші уподобання, які асистент застосовує всюди.
- **Уточнення (Disambiguations)** — пояснення, які асистент засвоїв (наприклад, якого саме «Івана» або який проєкт ви маєте на увазі), щоб він перестав помилятися в здогадках.

Самонавчання залежить від тарифу. Без нього асистент і далі використовує все, що ви додали самі, — він лише припиняє збирати нові факти самостійно.

## Налаштування

Відкрийте налаштування з меню користувача. Вкладки:

- **Загальні** — основні параметри, виявлений пристрій введення звуку та індикатори тесту мікрофона / системного звуку, підключення Google Календаря, параметри захоплення екрана та **Перевірка оновлень**.
- **Гарячі клавіші** — перегляд і перепризначення всіх сполучень клавіш.
- **Профіль** — ваші відповіді з онбордингу, пам'ять користувача та уточнення.
- **Безпека** — параметри безпеки облікового запису, зокрема пристрої, на яких виконано вхід. На тарифах з обмеженням в один пристрій вхід в іншому місці завершує сеанс тут.
- **Мова** — мова інтерфейсу / відповідей.
- **Ресурси** — завантаження та керування вашими документами Markdown, а також вибір тих, що увімкнені для активного проєкту (див. [Документи](#документи)).
- **Оплата** — ваша підписка і тариф: що до нього входить і як його змінити. Тариф відкриває платні функції — наприклад фоновий ІІ-чат, спільний доступ, а також ліміти на проєкти й документи.

## Оновлення

Elyvo Assist **не** оновлюється самостійно, але перевірка версії всупереч цьому відбувається автоматично: сервер періодично (приблизно раз на 8 годин, плюс один раз під час запуску сервера) опитує GitHub на нові релізи і, якщо знаходить новішу версію, надсилає на ваш Дашборд оголошення, яке можна закрити, **«New version!»** (заголовок залишається англійською) із посиланням на завантаження. Також можна будь-коли вручну натиснути **Перевірка оновлень** у **Налаштування → Загальні**, щоб одразу відкрити сторінку [Releases](https://github.com/pdasilem/elyvo-assist/releases) у браузері.

Щоб оновитися, завантажте найновіший інсталятор для вашої платформи з [Releases](https://github.com/pdasilem/elyvo-assist/releases) і запустіть його поверх наявної інсталяції — налаштування та вхід у систему збережуться.

- **Arch / Manjaro:** повторно запустіть `install.sh` з останнього релізу або виконайте `sudo pacman -U` для нового `.pkg.tar.zst`.
- **Debian / Ubuntu:** `sudo apt install ./elyvo-assist-<нова-версія>-linux-x86_64.deb`.
- **Windows / macOS:** запустіть новий інсталятор / відкрийте новий DMG.

> Користувачам Linux KDE з KWin, старшим за 6.7.0: повторно застосуйте патч KWin для знімків екрана після системного оновлення KWin, якщо ви покладаєтесь на захист від знімків екрана. Якщо оновлення підняло вас до KWin 6.7.0 або новішого, патч більше не потрібен — захист вбудовано.

## Видалення

- **Windows** — *Параметри → Застосунки → Встановлені застосунки → Elyvo Assist → Видалити*.
- **macOS** — перетягніть **Elyvo Assist** із папки *Applications* до Кошика.
- **Debian / Ubuntu** — `sudo apt remove elyvo-assist`.
- **Arch / Manjaro** — `sudo pacman -R elyvo-assist`.

## Усунення несправностей

**Оверлей не з'являється.** Переконайтеся, що застосунок запущено (перевірте трей / рядок меню) і натисніть гарячу клавішу перемикання (`Ctrl+\`). На macOS переконайтеся, що надано дозвіл Accessibility, інакше глобальні гарячі клавіші не спрацюють.

**Звук не захоплюється.** Перевірте доступ до мікрофона й захоплення екрана в налаштуваннях приватності вашої ОС, а потім скористайтеся тестом мікрофона / системного звуку в **Налаштування → Загальні**, щоб перевірити рівні. Elyvo використовує системний пристрій введення за замовчуванням, тому встановіть потрібний пристрій за замовчуванням у звукових налаштуваннях ОС. У Linux переконайтеся, що PipeWire запущено.

**Проблеми зі входом.** Спробуйте альтернативний спосіб (електронна пошта/пароль замість Google, чи навпаки) і переконайтеся, що системний годинник виставлено правильно — OAuth і перевірка токенів чутливі до часу.

**Вас несподівано розлогінило.** На тарифах з обмеженням в один пристрій вхід з іншого пристрою завершує сеанс тут — просто увійдіть знову. Список пристроїв облікового запису доступний у **Налаштування → Безпека**.

З усіх інших питань створюйте issue в [репозиторії релізів](https://github.com/pdasilem/elyvo-assist/issues).
