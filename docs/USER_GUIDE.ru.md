# Elyvo Assist — Руководство пользователя

> 🌐 Это руководство также доступно на: [English](USER_GUIDE.md) · [Беларуская](USER_GUIDE.be.md) · [Deutsch](USER_GUIDE.de.md) · [Español](USER_GUIDE.es.md) · [Français](USER_GUIDE.fr.md) · [Italiano](USER_GUIDE.it.md) · [Português](USER_GUIDE.pt.md) · **Русский** · [Українська](USER_GUIDE.uk.md)

Elyvo Assist — это десктопный ИИ-ассистент для встреч, исследований и мозговых штурмов. Он работает как полупрозрачный оверлей поверх любого окна и вызывается горячей клавишей. Он может слушать ваш микрофон и системный звук, расшифровывать речь в реальном времени, видеть ваш экран и отвечать на вопросы с учётом контекста.

Это руководство охватывает установку и обзор основных возможностей.

## Установка

Установщики и бинарные файлы публикуются в [GitHub Releases](https://github.com/pdasilem/elyvo-assist/releases). Скачайте файл, соответствующий вашей платформе, из последнего релиза. Все сборки 64-битные (`x86_64` / Apple Silicon).

Каждый релиз содержит для версии `X.Y.Z`:

| Платформа | Файл |
|-----------|------|
| Windows | `elyvo-assist-X.Y.Z-windows-x64-setup.exe` |
| macOS (Intel) | `elyvo-assist-X.Y.Z-macos-x64.dmg` |
| macOS (Apple Silicon) | `elyvo-assist-X.Y.Z-macos-arm64.dmg` |
| Debian / Ubuntu | `elyvo-assist-X.Y.Z-linux-x86_64.deb` |
| Arch / Manjaro | `elyvo-assist-X.Y.Z-1-x86_64.pkg.tar.zst` (+ `install.sh`) |

### Windows

1. Скачайте установщик `...-setup.exe` (NSIS).
2. Запустите его и следуйте инструкциям. Приложение устанавливается в `Program Files\Elyvo Assist`.
3. Запустите **Elyvo Assist** из меню «Пуск».

### macOS

1. Скачайте `.dmg` для вашего процессора — `macos-x64` для Intel, `macos-arm64` для Apple Silicon (M1/M2/M3 и новее).
2. Откройте образ диска и перетащите **Elyvo Assist** в папку **Applications**.
3. При первом запуске macOS может предупредить, что приложение от неизвестного разработчика. Кликните по приложению правой кнопкой → **Открыть** → **Открыть**, чтобы разрешить запуск.

> **Требования для Linux.** Elyvo Assist рассчитан на рабочий стол **KDE Plasma** на **Wayland**. Приложение интегрировано с KWin (композитором KDE). Другие окружения (GNOME и т. д.) могут запускать приложение, но поведение окна может отличаться. Также для захвата микрофона и системного звука необходим запущенный сеанс **PipeWire**.

### Linux — Debian / Ubuntu

```bash
sudo apt install ./elyvo-assist-X.Y.Z-linux-x86_64.deb
```

`apt` сам подтянет зависимости времени выполнения (WebKitGTK 4.1, OpenSSL 3, PipeWire). В старых версиях `apt` используйте `sudo dpkg -i ...`, а затем `sudo apt -f install`, чтобы доустановить недостающие зависимости.

### Linux — Arch / Manjaro

Самый быстрый путь — опубликованный скрипт установки, который скачивает пакет, устанавливает необходимые системные библиотеки и запускает `pacman` за вас:

```bash
curl -fsSL https://github.com/pdasilem/elyvo-assist/releases/latest/download/install.sh -o install.sh
bash install.sh
```

Скрипт поддерживает только системы на базе `pacman` и установит все недостающие пакеты времени выполнения (GTK3, WebKit2GTK 4.1, PipeWire, libayatana-appindicator и т. д.).

Предпочитаете сделать вручную? Скачайте `.pkg.tar.zst` и установите его напрямую:

```bash
sudo pacman -U elyvo-assist-X.Y.Z-1-x86_64.pkg.tar.zst
```

## Первый запуск

1. **Вход.** Войти можно по **электронной почте и паролю**, по **одноразовому коду из письма** или через **Google**. Новый аккаунт создаётся на том же экране (почта → код подтверждения → задать пароль).
2. **Онбординг.** Короткий мастер проведёт вас через несколько шагов — в том числе **разрешения** и **создание вашего первого проекта** — и завершится шагом **«О вас»**, где по желанию можно прикрепить файл (`.pdf`, `.doc`, `.docx`, `.md`, `.txt`), чтобы дать ассистенту больше контекста о вас. Это можно позже изменить в **Профиле**.
3. **Начало работы.** После онбординга открывается **Дашборд**. Вызвать оверлей чата можно в любой момент горячей клавишей переключения (по умолчанию `Ctrl+\`).

## Разрешения

Чтобы слушать и видеть ваш экран, Elyvo Assist нужны два разрешения на уровне ОС — их запрашивают во время онбординга:

- **Микрофон** — чтобы захватывать то, что вы говорите.
- **Захват экрана** — чтобы функция *«Спросить про экран»* видела активное окно.

На **Windows** и **macOS** это решается через обычные системные запросы. В **Linux** выдайте разрешения, когда их запросят; если вы случайно отклонили одно из них, выдайте его в настройках приватности вашей ОС.

Сами настройки звука и микрофона внутри приложения недоступны — Elyvo всегда использует **устройство по умолчанию**, заданное в системе.

> В Linux захват микрофона и системного звука использует PipeWire и desktop portal. Убедитесь, что PipeWire запущен (он включён по умолчанию в актуальных Manjaro и Ubuntu).

## Оверлей и горячие клавиши

Elyvo Assist управляется почти полностью с клавиатуры, чтобы вы могли пользоваться им, не отрываясь от встречи. Оверлей чата располагается поверх других окон, его можно перетаскивать.

Горячие клавиши по умолчанию (все переназначаются в **Настройки → Горячие клавиши**):

| Действие | По умолчанию | Что делает |
|----------|--------------|------------|
| Переключить видимость | `Ctrl+\` | Показать / скрыть оверлей Elyvo |
| Спросить Elyvo | `Ctrl+Enter` | Спросить про экран или текущий звук |
| Очистить чат | `Ctrl+R` | Очистить текущий разговор |
| Начать / остановить сессию | `Ctrl+Shift+\` | Начать или завершить сессию прослушивания |
| Переместить оверлей | `Ctrl+↑ / ↓ / ← / →` | Сдвинуть окно на экране |
| Прокрутить ответ | `Ctrl+Shift+↑ / ↓` | Прокрутить ответ вверх / вниз |

Чтобы переназначить, откройте **Настройки → Горячие клавиши**, кликните по сочетанию и нажмите новую комбинацию.

## Обзор возможностей

### Сессии

**Сессия** — это период, когда Elyvo активно слушает и удерживает контекст. Начать или остановить сессию можно сочетанием `Ctrl+Shift+\`. Во время сессии Elyvo захватывает ваш микрофон и системный звук, расшифровывает речь в реальном времени и хранит текущую расшифровку как контекст для ваших вопросов. Elyvo использует **системное устройство ввода по умолчанию** (изменить его в приложении нельзя); в настройках можно увидеть определённое устройство и протестировать уровни микрофона и системного звука по индикаторам в реальном времени.

### Спросить про экран или звук

Нажмите **Спросить Elyvo** (`Ctrl+Enter`), и Elyvo ответит, опираясь на то, что сейчас на экране, и недавний звук/расшифровку как контекст — удобно для «суммируй, что только что сказали», «что это за ошибка» или «набросай ответ на это». Также в любой момент можно просто ввести сообщение в поле чата.

### Быстрые действия

Во время сессии в чате доступны пять действий в один клик. Они **зависят от роли**: каждое берёт смысл из ситуации и цели активного режима, поэтому одна и та же кнопка помогает по-разному — отвечаете вы, оцениваете, ведёте переговоры или учитесь.

- **Assist** — суть, которая нужна в моменте: ответ на вопрос, который задали вам; эталонный ответ или быстрая оценка, когда оцениваете *вы*; полное решение, если на скриншоте задача. Это материал для размышления, а не слова для произнесения вслух.
- **What should I say?** — одна следующая реплика, которую стоит сказать вслух, вашим голосом, готовая как есть.
- **Follow-up questions** — набор из 3–4 вопросов, которые можно задать дальше, чтобы продвинуть вашу цель: меню на выбор, а не одна фраза.
- **What did they mean?** — расшифровка последней реплики собеседника: его мысль, намерение и невысказанное опасение.
- **Recap** — до трёх пунктов о том, что изменилось, было решено или спрошено с момента, когда вы сверялись в последний раз.

Как работает смена роли: в режиме кандидата Assist отвечает на вопрос, адресованный вам; в режиме оценивающего — даёт эталонный ответ, с которым можно сверить услышанное; в переговорном режиме Follow-up questions превращаются в вопросы для выяснения позиции. В режиме лекции или вебинара, где вы в основном слушаете, Assist объясняет только что прозвучавшую мысль проще, Follow-up questions становятся вопросами к спикеру или проверкой собственного понимания, а Recap помогает нагнать упущенное после отвлечения. Всем этим управляет системный промпт активного режима — кнопки остаются теми же (см. **Режимы ИИ** ниже).

### Режимы ИИ

**Режимы** позволяют настроить поведение ассистента под разные ситуации. У каждого режима есть собственный системный промпт и необязательный шаблон заметок. Управление — в разделе **Режимы**:

- Начните с **Галереи шаблонов** — её шаблоны предоставляет сервер и со временем меняются — или создайте режим с нуля.
- Отредактируйте системный промпт, задав тон, роль и правила для этой ситуации.
- Прикрепите **файлы режима** — справочные материалы, которые ассистент должен учитывать в этом режиме.
- Отметьте один режим активным; всегда доступен общий режим по умолчанию.

### Фоновый ИИ-чат (Ambient)

Фоновый чат — это лёгкий, всегда доступный чат, который следует за вами по приложению и может быть привязан к проекту. Он входит в платный тариф (см. **Настройки → Оплата**).

### Что даёт ваш тариф

Elyvo работает на любом тарифе; расширенная подписка снимает ограничения и открывает совместную работу. В общих чертах, более высокий тариф даёт:

- более длинные и более частые сессии;
- запас по количеству проектов и документов;
- возможность делиться проектом с другими людьми — принять приглашение и работать в чужом проекте можно на любом тарифе;
- использование приложения более чем на одном устройстве одновременно;
- самообучение ассистента, чтобы он становился лучше от ваших сессий.

Что включает ваш текущий тариф и как его изменить — в **Настройки → Оплата**. Где действует ограничение, приложение сообщит об этом в момент, когда вы его достигнете, а не откажет молча.

### Проекты

**Проекты** группируют связанные сессии и дают ассистенту общий, постоянный контекст. Внутри проекта можно управлять:

- **Участники** — посмотреть, кто в проекте, и пригласить других по электронной почте (каждый приглашённый отображается как *ожидает*, пока не примет приглашение). Отправка приглашений требует тарифа, включающего совместный доступ; принять приглашение и работать в чужом проекте можно на любом тарифе.
- **Память** — факты и контекст, которые ассистент должен помнить между сессиями этого проекта.
- **Правила** — указания, которым ассистент следует в этом проекте.
- **Настройки** — свои для проекта **режим**, **язык ответов** и **язык расшифровки**, а также **Обогащение контекста** — переключатель (по умолчанию выключен), который позволяет ассистенту подтягивать релевантный контекст из ваших *других* сессий в этом же проекте (кросс-сессионная память).

Когда *вас* приглашают в чужой проект, приглашение появляется вверху раздела **Проекты** с кнопками **Принять** / **Отклонить**. Фоновый чат можно привязать к проекту, чтобы ответы опирались на память и правила этого проекта.

Если тариф владельца перестаёт включать совместный доступ, общий проект становится **доступным только для чтения** для всех, пока из него не удалят участников. Ничего не удаляется, и полный доступ возвращается, как только проект перестаёт быть общим — либо тариф снова включает совместный доступ.

### Документы

Elyvo может хранить личную библиотеку справочных документов, которые можно открыть отдельным оверлеем прямо во время работы — удобно держать под рукой заметки, бриф или чек-лист во время звонка.

- **Управление документами.** В **Настройки → Ресурсы** добавляйте файлы Markdown (`.md`) — до **1 МБ** каждый — в разделе *Ваши документы* или удаляйте ненужные. Документы приватны и доступны только вам. Сколько документов можно хранить, зависит от вашего тарифа.
- **Включение для проекта.** Для активного проекта отметьте документы, которые хотите держать под рукой. Включённые документы **автоматически открываются вкладками** в просмотрщике «Документы» при его открытии для этого проекта. Включение документа определяет, что показывает просмотрщик для проекта; содержимое файла при этом не передаётся в ответы ассистента.
- **Открытие просмотрщика.** В меню сессии чат-оверлея (кнопка `···`) выберите **Документы**. Он откроется отдельным перетаскиваемым окном. Тот же пункт меню закрывает его.
- **Чтение и переключение.** Каждый документ открывается в своей вкладке. Кнопкой **+** откройте любой из ваших документов, кликом по вкладке переключайтесь между ними, а **×** закрывает вкладку. Содержимое отображается как отформатированный Markdown и следует теме чата и размеру шрифта.

### Календарь и встречи

Подключите **Google Календарь** (в **Настройки → Общие**), чтобы видеть предстоящие встречи прямо в Elyvo. На карточке встречи кнопка **«Присоединиться →»** просто открывает ссылку на звонок (Zoom/Meet/Teams) в браузере, а кнопка **«Начать заметки»** запускает сессию прослушивания. Незадолго до встречи Elyvo также показывает всплывающее напоминание внутри приложения со своей кнопкой **«Начать заметки»**, которая делает и то, и другое сразу — запускает сессию и открывает ссылку на звонок, — так что ассистент слушает с момента подключения.

### Дашборд и история

**Дашборд** — ваша домашняя страница: он показывает прошлые сессии списком с группировкой по датам и поиском (поле поиска находится в шапке приложения) и позволяет открыть детали сессии на трёх вкладках — **Сводка** (сводка встречи), **Расшифровка** (захваченная расшифровка) и **Использование** (вопросы, которые вы задавали Elyvo во время сессии, и его ответы). Используйте его, чтобы просматривать встречи или возвращаться к ним. На вкладке **Сводка** кнопка копирования копирует всю сводку целиком.

### Память и самообучение

Elyvo становится лучше с использованием. В вашем **Профиле** можно просматривать и редактировать:

- **Память пользователя** — долгоживущие факты о вас и ваших предпочтениях, которые ассистент применяет везде.
- **Уточнения (Disambiguations)** — пояснения, которые ассистент усвоил (например, какой именно «Иван» или какой проект вы имеете в виду), чтобы он перестал ошибаться в догадках.

Самообучение зависит от тарифа. Без него ассистент по-прежнему использует всё, что вы добавили сами, — он просто перестаёт собирать новые факты самостоятельно.

## Настройки

Откройте настройки из меню пользователя. Вкладки:

- **Общие** — основные параметры, определённое устройство ввода звука и индикаторы теста микрофона / системного звука, подключение Google Календаря, параметры захвата экрана и **Проверка обновлений**.
- **Горячие клавиши** — просмотр и переназначение всех сочетаний.
- **Профиль** — ваши ответы из онбординга, память пользователя и уточнения.
- **Безопасность** — параметры безопасности аккаунта, включая устройства, на которых выполнен вход. На тарифах с ограничением в одно устройство вход в другом месте завершает сеанс здесь.
- **Язык** — язык интерфейса / ответов.
- **Ресурсы** — загрузка и управление вашими документами Markdown и выбор тех, что включены для активного проекта (см. [Документы](#документы)).
- **Оплата** — ваша подписка и тариф: что в него входит и как его изменить. Тариф открывает платные функции — например фоновый ИИ-чат, совместный доступ, а также лимиты на проекты и документы.

## Обновление

Elyvo Assist **не** обновляется сам, но проверка версии всё же происходит автоматически: сервер периодически (примерно раз в 8 часов, плюс один раз при запуске сервера) опрашивает GitHub на предмет новых релизов и, если находит более новую версию, отправляет на ваш Дашборд закрываемое объявление **«New version!»** со ссылкой на скачивание. Также можно в любой момент вручную нажать **Проверка обновлений** в **Настройки → Общие**, чтобы сразу открыть страницу [Releases](https://github.com/pdasilem/elyvo-assist/releases) в браузере.

Чтобы обновиться, скачайте свежий установщик для вашей платформы из [Releases](https://github.com/pdasilem/elyvo-assist/releases) и запустите его поверх текущей установки — настройки и вход сохранятся.

- **Arch / Manjaro:** заново запустите `install.sh` из последнего релиза или выполните `sudo pacman -U` для нового `.pkg.tar.zst`.
- **Debian / Ubuntu:** `sudo apt install ./elyvo-assist-<новая-версия>-linux-x86_64.deb`.
- **Windows / macOS:** запустите новый установщик / откройте новый DMG.

> Пользователям Linux KDE с KWin старше 6.7.0: повторно примените патч KWin для скриншотов после системного обновления KWin, если вы полагаетесь на защиту от скриншотов. Если обновление привело вас к KWin 6.7.0 или новее, патч больше не нужен — защита встроена.

---

## Удаление

- **Windows** — *Параметры → Приложения → Установленные приложения → Elyvo Assist → Удалить*.
- **macOS** — перетащите **Elyvo Assist** из папки *Applications* в Корзину.
- **Debian / Ubuntu** — `sudo apt remove elyvo-assist`.
- **Arch / Manjaro** — `sudo pacman -R elyvo-assist`.

## Устранение неполадок

**Оверлей не появляется.** Убедитесь, что приложение запущено (проверьте трей / строку меню) и нажмите горячую клавишу переключения (`Ctrl+\`). На macOS проверьте, что выдано разрешение Accessibility, иначе глобальные горячие клавиши не сработают.

**Звук не захватывается.** Проверьте доступ к микрофону и захвату экрана в настройках приватности вашей ОС, затем воспользуйтесь тестом микрофона / системного звука в **Настройки → Общие**, чтобы проверить уровни. Elyvo использует системное устройство ввода по умолчанию, поэтому задайте нужное устройство по умолчанию в звуковых настройках ОС. В Linux убедитесь, что PipeWire запущен.

**Проблемы со входом.** Попробуйте альтернативный способ (почта/пароль или Google) и убедитесь, что системные часы выставлены верно — OAuth и проверка токенов чувствительны ко времени.

**Вас неожиданно разлогинило.** На тарифах с ограничением в одно устройство вход с другого устройства завершает сеанс здесь — просто войдите снова. Список устройств аккаунта доступен в **Настройки → Безопасность**.

По остальным вопросам создайте issue в [репозитории релизов](https://github.com/pdasilem/elyvo-assist/issues).
