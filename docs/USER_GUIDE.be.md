Elyvo Assist — гэта дэсктопны ІІ-асістэнт для сустрэч, даследаванняў і мазгавых штурмаў. Ён працуе як паўпразрысты оверлей паверх любога акна і выклікаецца гарачай клавішай. Ён можа слухаць ваш мікрафон і сістэмны гук, расшыфроўваць маўленне ў рэальным часе, бачыць ваш экран і адказваць на пытанні з улікам кантэксту — заставаючыся пры гэтым схаваным ад дэманстрацыі і запісу экрана.

## Усталяванне

Усталёўшчыкі і бінарныя файлы публікуюцца ў [GitHub Releases](https://github.com/pdasilem/elyvo-assist/releases). Спампуйце файл, які адпавядае вашай платформе, з апошняга рэлізу. Усе зборкі 64-бітныя (`x86_64` / Apple Silicon).

Кожны рэліз змяшчае для версіі `X.Y.Z`:

| Платформа | Файл |
|-----------|------|
| Windows | `elyvo-assist-X.Y.Z-windows-x64-setup.exe` |
| macOS (Intel) | `elyvo-assist-X.Y.Z-macos-x64.dmg` |
| macOS (Apple Silicon) | `elyvo-assist-X.Y.Z-macos-arm64.dmg` |
| Debian / Ubuntu | `elyvo-assist-X.Y.Z-linux-x86_64.deb` |
| Arch / Manjaro | `elyvo-assist-X.Y.Z-1-x86_64.pkg.tar.zst` (+ `install.sh`) |

### Windows

1. Спампуйце ўсталёўшчык `...-setup.exe` (NSIS).
2. Запусціце яго і прытрымлівайцеся інструкцый. Праграма ўсталёўваецца ў `Program Files\Elyvo Assist`.
3. Запусціце **Elyvo Assist** з меню «Пуск».

### macOS

1. Спампуйце `.dmg` для вашага працэсара — `macos-x64` для Intel, `macos-arm64` для Apple Silicon (M1/M2/M3 і навейшыя).
2. Адкрыйце вобраз дыска і перацягніце **Elyvo Assist** у папку **Applications**.
3. Пры першым запуску macOS можа папярэдзіць, што праграма ад невядомага распрацоўшчыка. Пстрыкніце па праграме правай кнопкай → **Open** → **Open**, каб дазволіць запуск.

> **Патрабаванні для Linux.** Elyvo Assist разлічаны на працоўны стол **KDE Plasma** пад **Wayland**. Абарона оверлея ад захопу экрана рэалізавана праз KWin (кампазітар KDE), таму хаванне ад дэманстрацыі экрана працуе толькі ў KDE/KWin. Іншыя асяроддзі (GNOME і інш.) могуць запускаць праграму, але гарантыі абароны ад захопу на іх не дзейнічаюць. Таксама для захопу мікрафона і сістэмнага гуку неабходна запушчаная сесія **PipeWire**.

### Linux — Debian / Ubuntu

```bash
sudo apt install ./elyvo-assist-X.Y.Z-linux-x86_64.deb
```

`apt` сам падцягне залежнасці часу выканання (WebKitGTK 4.1, OpenSSL 3, PipeWire). У старых версіях `apt` выкарыстоўвайце `sudo dpkg -i ...`, а потым `sudo apt -f install`, каб дадаткова ўсталяваць адсутныя залежнасці.

### Linux — Arch / Manjaro

Самы хуткі шлях — апублікаваны скрыпт усталявання, які спампоўвае пакет, устанаўлівае неабходныя сістэмныя бібліятэкі і запускае `pacman` за вас:

```bash
curl -fsSL https://github.com/pdasilem/elyvo-assist/releases/latest/download/install.sh -o install.sh
bash install.sh
```

Скрыпт падтрымлівае толькі сістэмы на базе `pacman` і ўсталюе ўсе адсутныя пакеты часу выканання (GTK3, WebKit2GTK 4.1, PipeWire, libayatana-appindicator і г. д.).

Аддаяце перавагу зрабіць гэта ўручную? Спампуйце `.pkg.tar.zst` і ўсталюйце яго напрамую:

```bash
sudo pacman -U elyvo-assist-X.Y.Z-1-x86_64.pkg.tar.zst
```

## Першы запуск

1. **Уваход.** Увайсці можна праз **электронную пошту і пароль**, праз **аднаразовы код з ліста** альбо праз **Google**. Новы акаўнт ствараецца на тым жа экране (пошта → код пацвярджэння → задаць пароль).
2. **Анбордынг.** Кароткі майстар правядзе вас праз некалькі крокаў — у тым ліку **дазволы** і **стварэнне вашага першага праекта** — і завершыцца крокам **«Пра вас»**, дзе па жаданні можна прымацаваць файл (`.pdf`, `.doc`, `.docx`, `.md`, `.txt`), каб даць асістэнту больш кантэксту пра вас. Гэта можна пазней змяніць у **Профілі**.
3. **Пачатак працы.** Пасля анбордынгу адкрываецца **Панэль кіравання**. Выклікаць оверлей чата можна ў любы момант гарачай клавішай пераключэння (па змаўчанні `Ctrl+\`).

## Дазволы

Каб слухаць і бачыць ваш экран, Elyvo Assist патрэбныя два дазволы на ўзроўні АС — іх запытваюць падчас онбордынгу:

- **Мікрафон** — каб захопліваць тое, што вы кажаце.
- **Захоп экрана** — каб функцыя *«Спытаць пра экран»* бачыла актыўнае акно.

На **Windows** і **macOS** гэта вырашаецца праз звычайныя сістэмныя запыты. У **Linux** выдавайце дазволы, калі іх запытаюць; калі вы выпадкова адхілілі адзін з іх, выдайце яго ў наладках прыватнасці вашай АС.

Самі налады гуку і мікрафона ўнутры праграмы не даступныя — Elyvo заўсёды выкарыстоўвае **прадвызначаную прыладу**, зададзеную ў сістэме.

> У Linux захоп мікрафона і сістэмнага гуку выкарыстоўвае PipeWire і desktop portal. Пераканайцеся, што PipeWire запушчаны (ён уключаны па змаўчанні ў актуальных Manjaro і Ubuntu).

## Оверлей і гарачыя клавішы

Elyvo Assist кіруецца амаль поўнасцю з клавіятуры, каб вы маглі карыстацца ім, не адрываючыся ад сустрэчы. Оверлей чата размяшчаецца паверх іншых вокнаў, яго можна перацягваць, і ён **схаваны ад дэманстрацыі і запісу экрана** (гл. [абарону акна](../README.md#window-protection-from-screen-sharing)).

Гарачыя клавішы па змаўчанні (усе можна пераназначыць у **Наладкі → Спалучэнні клавіш**):

| Дзеянне | Па змаўчанні | Што робіць |
|---------|--------------|------------|
| Пераключыць бачнасць | `Ctrl+\` | Паказаць / схаваць оверлей Elyvo |
| Спытаць Elyvo | `Ctrl+Enter` | Спытаць пра экран альбо бягучы гук |
| Ачысціць чат | `Ctrl+R` | Ачысціць бягучую размову |
| Пачаць / спыніць сесію | `Ctrl+Shift+\` | Пачаць альбо завяршыць сесію праслухоўвання |
| Перамясціць оверлей | `Ctrl+↑ / ↓ / ← / →` | Пераставіць акно на экране |
| Пракруціць адказ | `Ctrl+Shift+↑ / ↓` | Пракруціць адказ уверх / уніз |

Каб пераназначыць, адкрыйце **Наладкі → Спалучэнні клавіш**, пстрыкніце па спалучэнні і націсніце новую камбінацыю.

## Агляд магчымасцей

### Сесіі

**Сесія** — гэта перыяд, калі Elyvo актыўна слухае і ўтрымлівае кантэкст. Пачаць альбо спыніць сесію можна спалучэннем `Ctrl+Shift+\`. Падчас сесіі Elyvo захоплівае ваш мікрафон і сістэмны гук, расшыфроўвае маўленне ў рэальным часе і захоўвае бягучую расшыфроўку як кантэкст для вашых пытанняў. Elyvo выкарыстоўвае **сістэмную прыладу ўводу па змаўчанні** (змяніць яе ў праграме нельга); у наладках можна ўбачыць вызначаную прыладу і праверыць узроўні мікрафона і сістэмнага гуку па індыкатарах у рэальным часе.

### Спытаць пра экран або гук

Націсніце **Спытаць Elyvo** (`Ctrl+Enter`), і Elyvo адкажа, абапіраючыся на тое, што зараз на экране, і нядаўні гук/расшыфроўку як кантэкст — зручна для «падсумуй, што толькі што сказалі», «што гэта за памылка» ці «накідай адказ на гэта». Таксама ў любы момант можна проста ўвесці паведамленне ў поле чата.

### Хуткія дзеянні

Падчас сесіі ў чаце даступныя пяць дзеянняў у адзін клік. Яны **залежаць ад ролі**: кожнае бярэ сэнс з сітуацыі і мэты актыўнага рэжыму, таму адна і тая ж кнопка дапамагае па-рознаму — вы адказваеце, ацэньваеце, вядзеце перамовы ці вучыцеся.

- **Assist** — сутнасць, патрэбная ў моманце: адказ на пытанне, зададзенае вам; эталонны адказ або хуткая ацэнка, калі ацэньваеце *вы*; поўнае рашэнне, калі на скрыншоце задача. Гэта матэрыял для роздуму, а не словы для агучвання.
- **What should I say?** — адна наступная рэпліка, якую варта сказаць уголас, вашым голасам, гатовая як ёсць.
- **Follow-up questions** — набор з 3–4 пытанняў, якія можна задаць далей, каб прасунуць вашу мэту: меню на выбар, а не адна фраза.
- **What did they mean?** — расшыфроўка апошняй рэплікі суразмоўцы: яго думка, намер і невыказаная заклапочанасць.
- **Recap** — да трох пунктаў пра тое, што змянілася, было вырашана ці спытана з моманту, калі вы зверыліся апошні раз.

Як працуе змена ролі: у рэжыме кандыдата Assist адказвае на пытанне, адрасаванае вам; у рэжыме ацэншчыка — дае эталонны адказ, з якім можна зверыць пачутае; у перамоўным рэжыме Follow-up questions ператвараюцца ў пытанні для высвятлення пазіцыі. У рэжыме лекцыі або вебінара, дзе вы пераважна слухаеце, Assist тлумачыць толькі што прагучалую думку прасцей, Follow-up questions становяцца пытаннямі да спікера або праверкай уласнага разумення, а Recap дапамагае нагнаць прапушчанае пасля адцягнення. Усім гэтым кіруе сістэмны промпт актыўнага рэжыму — кнопкі застаюцца тымі ж (гл. **Рэжымы ІІ** ніжэй).

### Рэжымы ІІ

**Рэжымы** дазваляюць наладзіць паводзіны асістэнта пад розныя сітуацыі. У кожнага рэжыму ёсць уласны сістэмны промпт і неабавязковы шаблон нататак. Кіраванне — у раздзеле **Рэжымы**:

- Пачніце з **Галерэі шаблонаў** — яе шаблоны прадастаўляе сервер і з часам змяняюцца — альбо стварыце рэжым з нуля.
- Адрэдагуйце сістэмны промпт, задаўшы тон, ролю і правілы для гэтай сітуацыі.
- Прымацуйце **файлы рэжыму** — даведачныя матэрыялы, якія асістэнт павінен улічваць у гэтым рэжыме.
- Пазначце адзін рэжым актыўным; заўсёды даступны агульны рэжым па змаўчанні.

### Фонавы ІІ-чат (Ambient)

Фонавы чат — гэта лёгкі, заўсёды даступны чат, які суправаджае вас па праграме і можа быць прывязаны да праекта. Ён уваходзіць у платны тарыф (гл. **Наладкі → Аплата**).

### Праекты

**Праекты** групуюць звязаныя сесіі і даюць асістэнту агульны, пастаянны кантэкст. Унутры праекта можна кіраваць:

- **Удзельнікі** — паглядзець, хто ў праекце, і запрасіць іншых па электроннай пошце (кожны запрошаны паказваецца як *чакае*, пакуль не прыме запрашэнне).
- **Памяць** — факты і кантэкст, якія асістэнт павінен памятаць паміж сесіямі гэтага праекта.
- **Правілы** — указанні, якім асістэнт прытрымліваецца ў гэтым праекце.
- **Наладкі** — уласныя для праекта **рэжым**, **мова адказаў** і **мова расшыфроўкі**, а таксама **Узбагачэнне кантэксту** — пераключальнік (па змаўчанні выключаны), які дазваляе асістэнту падцягваць рэлевантны кантэкст з вашых *іншых* сесій у гэтым жа праекце (кросс-сесійная памяць).

Калі *вас* запрашаюць у чужы праект, запрашэнне з'яўляецца ўверсе раздзела **Праекты** з кнопкамі **Прыняць** / **Адхіліць**. Фонавы чат можна прывязаць да праекта, каб адказы абапіраліся на памяць і правілы гэтага праекта.

### Дакументы

Elyvo можа захоўваць асабістую бібліятэку даведачных дакументаў, якія можна адкрыць асобным оверлеем прама падчас працы — зручна трымаць пад рукой нататкі, брыф альбо чэк-ліст падчас званка.

- **Кіраванне дакументамі.** У **Наладкі → Рэсурсы** дадавайце файлы Markdown (`.md`) — да **1 МБ** кожны — у раздзеле *Вашы дакументы* альбо выдаляйце непатрэбныя. Дакументы прыватныя і даступныя толькі вам.
- **Уключэнне для праекта.** Для актыўнага праекта адзначце дакументы, якія хочаце трымаць пад рукой. Уключаныя дакументы **аўтаматычна адкрываюцца ўкладкамі** ў праглядальніку «Дакументы» пры яго адкрыцці для гэтага праекта. Уключэнне дакумента вызначае, што паказвае праглядальнік для праекта; змест файла пры гэтым не перадаецца ў адказы асістэнта.
- **Адкрыццё праглядальніка.** У меню сесіі оверлея чата (кнопка `···`) абярыце **Дакументы**. Ён адкрыецца асобным акном, якое можна перацягваць і якое, як і асноўны оверлей, **схавана ад дэманстрацыі і запісу экрана**. Той жа пункт меню закрывае яго.
- **Чытанне і пераключэнне.** Кожны дакумент адкрываецца ва ўласнай укладцы. Кнопкай **+** адкрыйце любы з вашых дакументаў, пстрычкай па ўкладцы пераключайцеся паміж імі, а **×** закрывае ўкладку. Змест адлюстроўваецца як фарматаваны Markdown і прытрымліваецца тэмы чата і памеру шрыфту.

### Каляндар і сустрэчы

Падключыце **Google Каляндар** (у **Наладкі → Агульныя**), каб бачыць будучыя сустрэчы прама ў Elyvo. На картцы сустрэчы кнопка **«Далучыцца →»** проста адкрывае спасылку на званок (Zoom/Meet/Teams) у браўзеры, а кнопка **«Пачаць нататкі»** запускае сесію праслухоўвання. Незадоўга да сустрэчы Elyvo таксама паказвае напамін унутры праграмы з уласнай кнопкай **«Пачаць нататкі»**, якая робіць абодва дзеянні адразу — запускае сесію і адкрывае спасылку на званок, — каб асістэнт слухаў з моманту далучэння.

### Панэль кіравання і гісторыя

**Панэль кіравання** — ваша хатняя старонка: яна паказвае мінулыя сесіі спісам з групоўкай па датах і пошукам (поле пошуку знаходзіцца ў шапцы праграмы) і дазваляе адкрыць дэталі сесіі на трох укладках — **Зводка** (зводка сустрэчы), **Расшыфроўка** (захопленая расшыфроўка) і **Выкарыстанне** (пытанні, якія вы задавалі Elyvo падчас сесіі, і яго адказы). Выкарыстоўвайце яе, каб праглядаць сустрэчы альбо вяртацца да іх.

### Памяць і саманавучанне

Elyvo становіцца лепшым з выкарыстаннем. У вашым **Профілі** можна праглядаць і рэдагаваць:

- **Памяць карыстальніка** — доўгажывучыя факты пра вас і вашы перавагі, якія асістэнт прымяняе паўсюль.
- **Удакладненні (Disambiguations)** — тлумачэнні, якія асістэнт засвоіў (напрыклад, які менавіта «Іван» альбо які праект вы маеце на ўвазе), каб ён перастаў памыляцца ў здагадках.

### Абарона акна ад дэманстрацыі экрана

Оверлей наўмысна нябачны для захопу, каб вы маглі карыстацца ім падчас сумеснага званка і каб ён не трапляў у трансляцыю. Ахоп адрозніваецца па платформах — аўтарытэтная табліца прыведзена ў [асноўным README](../README.md#window-protection-from-screen-sharing). Каратка:

- **Windows 11** — схаваны ад усіх тыпаў захопу «з каробкі».
- **Windows 10** — той жа механізм, але **не гарантавана**: з-за асаблівасці АС акно можа адлюстроўвацца ў захопе як чорны прамавугольнік замест поўнага хавання.
- **Linux (KDE / KWin)** — схаваны ад *запісу і дэманстрацыі* экрана «з каробкі». На **KWin 6.7.0+ (Plasma 6.7+)** статычныя *здымкі экрана* таксама схаваныя «з каробкі» — патч не патрэбны. На больш старых KWin (≤ 6.6.x), каб схаваць яго ад статычных *здымкаў экрана* (Spectacle/PrintScreen), патрэбны аднаразовы патч KWin, які трэба паўторна прымяняць пасля абнаўленняў KWin.
- **macOS** — выкарыстоўвае той жа натыўны механізм абароны кантэнту. Надзейна працуе на **macOS 14 і больш ранніх**; на **macOS 15 і навейшых** незаўважнасць **не гарантуецца**, і оверлей можа трапіць у захоп.

## Абнаўленне

Elyvo Assist **не** абнаўляецца сам, але праверка версіі ўсё ж адбываецца аўтаматычна: сервер перыядычна (прыкладна раз на 8 гадзін, плюс адзін раз пры запуску сервера) правярае GitHub на новыя рэлізы і, калі знаходзіць навейшую версію, адпраўляе на вашу Панэль кіравання абвестку **«New version!»**, якую можна закрыць, са спасылкай на спампоўванне. Таксама можна ў любы момант уручную націснуць **Праверка абнаўленняў** у **Наладкі → Агульныя**, каб адразу адкрыць старонку [Releases](https://github.com/pdasilem/elyvo-assist/releases) у браўзеры.

Каб абнавіцца, спампуйце свежы ўсталёўшчык для вашай платформы з [Releases](https://github.com/pdasilem/elyvo-assist/releases) і запусціце яго паверх бягучага ўсталявання — наладкі і ўваход захаваюцца.

- **Arch / Manjaro:** зноў запусціце `install.sh` з апошняга рэлізу альбо выканайце `sudo pacman -U` для новага `.pkg.tar.zst`.
- **Debian / Ubuntu:** `sudo apt install ./elyvo-assist-<новая-версія>-linux-x86_64.deb`.
- **Windows / macOS:** запусціце новы ўсталёўшчык / адкрыйце новы DMG.

> Карыстальнікам Linux KDE з KWin, старэйшым за 6.7.0: паўторна прымяніце патч KWin для здымкаў экрана пасля сістэмнага абнаўлення KWin, калі вы спадзеяцеся на абарону ад здымкаў экрана. Калі абнаўленне прывяло вас да KWin 6.7.0 або навейшага, патч больш не патрэбны — абарона ўбудаваная.

## Выдаленне

- **Windows** — *Параметры → Праграмы → Усталяваныя праграмы → Elyvo Assist → Выдаліць*.
- **macOS** — перацягніце **Elyvo Assist** з папкі *Applications* у Кошык.
- **Debian / Ubuntu** — `sudo apt remove elyvo-assist`.
- **Arch / Manjaro** — `sudo pacman -R elyvo-assist`.

## Вырашэнне праблем

**Оверлей не з'яўляецца.** Пераканайцеся, што праграма запушчана (праверце трэй / радок меню), і націсніце гарачую клавішу пераключэння (`Ctrl+\`). На macOS праверце, што выдадзены дазвол Accessibility, інакш глабальныя гарачыя клавішы не спрацуюць.

**Гук не захопліваецца.** Праверце доступ да мікрафона і захопу экрана ў наладках прыватнасці вашай АС, а потым скарыстайцеся тэстам мікрафона / сістэмнага гуку ў **Наладкі → Агульныя**, каб праверыць узроўні. Elyvo выкарыстоўвае сістэмную прыладу ўводу па змаўчанні, таму задайце патрэбную прыладу па змаўчанні ў гукавых наладках АС. У Linux пераканайцеся, што PipeWire запушчаны.

**Оверлей усё яшчэ бачны на здымках экрана ў Linux.** *Запіс/дэманстрацыя* экрана схаваныя па змаўчанні. На KWin 6.7.0+ (Plasma 6.7+) здымкі экрана схаваныя «з каробкі»; на больш старых KWin для статычных здымкаў экрана патрэбны аднаразовы патч KWin, апісаны ў [README](../README.md#window-protection-from-screen-sharing) — прымяняйце яго паўторна пасля абнаўленняў KWin.

**Праблемы са ўваходам.** Паспрабуйце альтэрнатыўны спосаб (пошта/пароль альбо Google) і пераканайцеся, што сістэмны гадзіннік выстаўлены правільна — OAuth і праверка токенаў адчувальныя да часу.

Па астатніх пытаннях стварыце issue ў [рэпазітарыі рэлізаў](https://github.com/pdasilem/elyvo-assist/issues).
